# 📄Empowering Women with Predictive Safety Analytics
## 📌 Project Overview

This project focuses on improving women’s safety by predicting high-risk locations and time windows using machine learning techniques. The system identifies potential danger zones based on historical crime and safety incident data, enabling authorities and communities to take preventive measures. The results are presented through an interactive Power BI dashboard and safety map for easy decision-making.

## 🎯 Objectives

To analyze crime patterns affecting women’s safety.

To build a predictive model to identify at-risk zones and time periods.

To visualize safety insights using Power BI for awareness and intervention.

To support better planning for surveillance, patrolling, and community safety.

## 🔍 Approach & Methodology

1.Data Collection & Cleaning

Crime and incident data categorized by location, time, crime type, seasons, etc.

Data preprocessing handled using Python (Pandas, NumPy).

2.Model Development

Machine learning model developed using scikit-learn.

Compared multiple models to find the best-performing algorithm.

Achieved ~30% improvement in prediction accuracy vs baseline.

3.Visualization & Reporting

Created interactive maps and dashboards in Power BI.

Highlighted at-risk zones, hotspots, incident trends, and prediction outputs.

Enabled filters for location, time, crime category, severity and more.

## 📊 Features

Predicts high-risk areas for women's safety.

Time-based alerts for increased vulnerability.

Location-wise incident visualization on map.

Trend analysis with monthly/yearly breakdowns.

Data-driven insights to support interventions.

Decision dashboard for authorities and NGOs.

## 🛠 Technologies Used

Python: Data preprocessing, ML modeling

scikit-learn: Predictive safety model

Power BI: Dashboards & interactive safety map

Pandas, NumPy, Matplotlib/Seaborn (optional)

Geo/Location Data (Heatmapping)

## 📈 Outcome

The project successfully delivered a predictive safety solution that highlighted unsafe zones and time windows affecting women. It improved situational awareness and helped drive targeted safety campaigns and interventions. The final dashboard enabled stakeholders to make faster, data-based decisions.
